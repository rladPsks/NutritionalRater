# Nutritional Products Rater

A barcode-based nutrition analysis and food recommendation system developed as a **team project for an Artificial Intelligence course at San Diego State University (SDSU)**.

The system evaluates packaged food products using nutritional information and additive risk, assigns an overall health score, and suggests higher-rated alternatives from the same product category. The project also applies **K-means clustering** to analyze nutritional patterns across product categories.

> **Team project:** This project was developed collaboratively by four students.
---

## Overview

The project was designed to help users compare packaged food products using a simple barcode-driven workflow.

Given a product barcode, the application:

1. Looks up the corresponding product in the prepared dataset
2. Computes a nutrition-based score
3. Evaluates listed additives
4. Produces an overall health rating from 0 to 100
5. Recommends up to five higher-rated alternatives from the same category

The repository also includes a K-means pipeline for grouping products by nutritional profile.

---

## How It Works

### 1. Product Lookup

The user enters a product barcode through the command-line interface.

```text
Barcode
   ↓
Product lookup
   ↓
Nutrition + additive analysis
   ↓
Overall health score
   ↓
Healthier alternatives
```

### 2. Nutrition Scoring

The nutrition score considers product-level nutritional features such as:

- energy
- sugars
- saturated fat
- salt
- fiber
- protein

The scoring logic applies nutrient penalties and bonuses to produce a normalized nutrition-quality score.

### 3. Additive Scoring

The system also evaluates listed additives using a risk dictionary.

Additives are grouped into risk levels such as:

- no risk
- limited risk
- high risk

Higher-risk additives reduce the additive-quality score more strongly.

### 4. Final Health Rating

The final product rating combines:

- **60% nutrition score**
- **40% additive score**

The resulting score is reported on a **0–100 scale**.

### 5. Healthier Alternatives

The recommendation module searches within the same product category and returns up to five products with a higher health rating.

---

## Machine Learning Component

The project uses **K-means clustering** to identify nutritional patterns within product categories.

Each category is modeled separately using the following standardized nutritional features:

- energy per 100 g
- fat
- saturated fat
- sugars
- fiber
- protein
- salt

A separate scaler and K-means model are trained for each category.

The number of clusters can be selected per category using the analysis outputs generated by `visualize_k.py`; otherwise, the training pipeline falls back to a default cluster count.

The trained models and scalers are stored in the `models/` directory.

## Installation

Clone this repository:

```bash
git clone https://github.com/rladPsks/NutritionalRater.git
cd NutritionalRater
```

Create and activate a virtual environment if desired:

```bash
python -m venv venv
```

**macOS / Linux**

```bash
source venv/bin/activate
```

**Windows**

```bash
venv\Scripts\activate
```

Install the required packages:

```bash
pip install -r requirements.txt
```

---

## Running the Project

Run:

```bash
python main.py
```

If the K-means selection summary is available under:

```text
reports/figures/k_selection_summary.csv
```

the application checks the clustering configuration at startup.

For additional analysis and cluster visualizations, see:

```text
visualize_k.py
```

and the `doc/` and `reports/` directories.
